# Appearance and readability

Open **Settings → Appearance** on the desktop app.

- **Text size**: 100%, 115%, 130%, 150%. The window grows with the chosen size so
  the action bar stays visible, and is capped/centered to the current desktop
  resolution.
- **Theme**: Dark (default), Light, or High contrast.
- **Apply** applies the change immediately.
- `Ctrl` + `+` / `Ctrl` + `-` changes the text size without opening Settings;
  `Ctrl` + `0` resets to 100%.

Settings are saved in:

```text
~/.config/sak-modern/settings.ini
```

The Android APK follows the system font/display size and does not currently have
a separate in-app theme picker.
